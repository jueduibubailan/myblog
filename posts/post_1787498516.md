# **POMO：基于多重最优策略的强化学习方法**

# **一、**

本文要精读的是《POMO: Policy Optimization with Multiple Optima for Reinforcement Learning》（Yeong-Dae Kwon, Jinho Choo, Byoungjip Kim, Iljoo Yoon, Youngjune Gwon, Seungjai Min，Samsung SDS，NeurIPS 2020，arXiv:2010.16011）。

核心思想：利用组合优化问题最优解在序列表示下的**对称性（多重表示）**，把多个起点都作为独立 rollout 放进训练，配合**共享基线（Shared Baseline）**和**多贪心推理（Multi-Greedy）**，在 TSP / CVRP / 0-1 KP 上都大幅超越当时的 SOTA（TSP100 最优性差距 **0.14%**，推理还快一个量级）。

# **其他**

以下内容为 POMO 的补充笔记：关键名词、公式拆解、图片说明，以及论文核心内容的通俗总结。

# **关键名词**

## **1、低方差基线**

策略梯度估计中引入的**基线（Baseline）** $b(s)$ 只改变梯度的方差、不改变其期望（无偏）。方差越低，训练越稳定、收敛越快。常见做法包括：用平均奖励、用价值函数估计，或用单独的策略（如贪婪 rollout）生成基线；POMO 的共享基线（batch 内所有轨迹的平均）就是一种低方差基线。

## **2、蒙特卡洛方法**

蒙特卡洛（Monte Carlo）方法通过**大量随机采样**来近似难以直接计算的期望/积分。在强化学习中，REINFORCE 就是一种蒙特卡洛策略梯度算法：完整跑完一条轨迹（episode）后，用轨迹的真实回报来估计策略梯度，而不是依赖对环境模型的推导。POMO 中每条轨迹 $\tau^i$ 就是通过蒙特卡洛采样得到的。

## **3、贪婪推演基线**

贪婪推演基线（greedy rollout baseline）来自 Attention Model（Kool et al., 2019）：维护一个“到目前为止最好模型”的副本，对同一实例用**确定性贪婪解码**得到一条解，以其代价作为基线 $b(s)$。它比平均奖励基线方差更低，但需要定期同步策略副本，且要多一次前向计算。POMO 的共享基线正是拿它来做对比的。

# **公式**

## **1、策略梯度定理（Policy Gradient Theorem）**

这个公式是**策略梯度定理（Policy Gradient Theorem）**的一种具体应用形式，它告诉我们要如何调整 AI 模型内部的参数（$\theta$），才能让模型变得越来越聪明。

我们可以把它拆解为三个部分来看：

### **1. 左边：∇θJ(θ)**

**含义**：这是**目标**。它代表“我们要优化的目标函数对参数的梯度”。

**通俗理解**：你可以把它看作一个**指南针**。它指示了模型参数 $\theta$ 需要调整的方向和幅度。顺着这个方向微调参数，模型解决问题的成功率就会提高。

### **2. 右边的大分数：∑/N**

**含义**：这是**求平均**。

**通俗理解**：AI 并不是只尝试一次，而是尝试了 N 次（比如让模型从 N 个不同的起点各跑一遍路线）。这里就是把这 N 次尝试的结果加起来取平均值，这样算出来的方向会更准确、更稳定，不会因为这其中某一次的运气好坏而跑偏。

### **3. 核心括号里的内容：(R(τi)−bi(s))**

**含义**：这是**奖励信号（Advantage，优势函数）**。这是整个公式的灵魂。

* **$R(\tau\_i)$**：这是第 i 次尝试得到的**最终得分**（比如这条路线的总长度）；
* **$b\_i(s)$**：这是一个**基准线（Baseline）**，通常取当前状态下所有路线得分的平均值。

**通俗理解**：这就是 POMO 算法的核心技巧——**“相互比较”**。我们不关心这条路绝对有多短，只关心它比平均水平（$b\_i$）好多少。

* 如果比平均好（$R > b$），这个差值就是**正数**，说明这个走法值得鼓励，参数就往这个方向调；
* 如果比平均差（$R < b$），差值就是**负数**，说明这个走法是坑，参数就反向调整去避开它。

### **4. 最后一部分：∇θlogpθ(τi∣s)**

**含义**：这是**策略的梯度**。

**通俗理解**：这代表了模型在做决定时的“倾向性”。如果模型在某一步特别倾向于选择某个动作（比如明明有捷径却非要走远路），这部分就会显示出偏差。它的作用是告诉模型：**“既然刚才那个走法效果不错（碰到了正数），那以后遇到类似情况，就要增加这种走法的概率。”**

---

### **总结起来**

这个公式的完整逻辑是：

> **“把模型在多次尝试中（比平均水平）表现优异的那些走法找出来，然后调整模型内部的参数，让模型以后更倾向于做出这些聪明的选择。”**

## **2、共享基准线（Shared Baseline）**

这个公式展示的是 POMO 算法中一个非常关键的机制：**共享基准线（Shared Baseline）**。

简单来说，它的目的是为了让 AI 在“学习”的时候，判断标准更加客观，避免因为运气不好而被误导。

我们可以分两部分来通俗地理解它：

**1. 等号右边：算出一个“全班平均分”**

这部分是在计算**所有**路径的平均得分。

想象一下，AI 尝试了 N 条不同的路线。不管某条路线走得好还是坏，把它们全部加起来除以 N，这就得到了一个“基准线”或者说“平均水平”。

**2. 等号左边：大家共用一个标准**

这部分是说，对于**每一次尝试**（第 i 次），AI 用来做比较的基准线，都是上面算出来的那个“全班平均分”，而不是各自分开算各自的。

**为什么要这么做？（结合上一轮的公式）**

在上一轮的公式中，我们有 $(R - b)$ 这一项，它的意思是“比基准线好多少”。

* **如果不共享（传统做法）**：假设 AI 走了 10 条路，它会把这 10 条路分成 10 组，每组自己跟自己比。如果这 10 条路都很烂，大家的得分都很高（比如都很长），那 AI 会觉得“大家都挺高分的，我挺棒的”，从而失去了改进的动力；
* **共享之后（POMO 的做法）**：不管哪条路，都拿它去跟那个“全班平均分”比。如果你的路线比平均分短，说明你是优等生，AI 就会记下这个走法，以后多学着点；如果你的路线比平均分长，说明你是差生，AI 就会惩罚这个走法，以后尽量避开。

**总结一句话：**

这个公式的意思就是**“把所有尝试过的路线放在一起算个总平均分，然后用这个统一的总平均分去衡量每一条路线的好坏”**。这样能让 AI 的判断极其稳定，练得又快又准。

这篇是 Samsung SDS 团队发表在 **NeurIPS 2020** 的 **POMO: Policy Optimization with Multiple Optima**，核心是给神经组合优化（Neural CO）的 RL 训练换了一套利用“解对称性”的玩法，在 TSP / CVRP / 0-1 KP 上都把当时的 SOTA 压了一大截（TSP100 最优性差距 **0.14%**，推理还快一个量级）。

## **一、Motivation：CO 解的"多重表示"被浪费了**

很多 CO 问题的最优解在序列表示下**不唯一**。比如 TSP 里 `(v1,v2,v3,v4,v5)` 和 `(v2,v3,v4,v5,v1)` 是同一个环。

但之前的 Attention Model（Kool et al., 2019）用了一个**可训练的 START token** 来决定第一个节点，导致：

* 网络被迫在所有“等价好的起点”里挑一个偏好 → 引入 bias；
* 探索被锁死在单一最优路径附近。

POMO 的思路很直：既然多个起点都能通向最优，**干脆把多个起点都作为独立 rollout 放进训练**。

---

## **二、POMO 的三个核心设计**

### **1. 多起点并行探索（训练）**

* 对一个问题实例，手动指定 **N 个不同起始节点** ${a\_1^1, a\_1^2, \dots, a\_1^N}$（TSP 就是每个节点都当一次起点，故 N = 问题规模）；
* 每条轨迹 $\tau^i$ 用 Monte-Carlo 采样得到；
* 区别于“START token + 多采样”：POMO 的 N 条轨迹对应 N 个**不同的节点序列表示**的最优解，而非挤在同一条最优路径上扰动。

### **2. 共享 baseline（梯度方差骤降）**

REINFORCE 的梯度近似：

$$\nabla*\theta J \approx \frac{1}{N}\sum*{i=1}^{N} (R(\tau\_i) - b\_i(s)) \nabla*\theta \log p*\theta(\tau\_i \mid s)$$

POMO 取 **batch 内共享 baseline**：

$$b*{shared} = \frac{1}{N}\sum*{j=1}^{N} R(\tau\_j)$$

优势（对比 Kool 的 greedy-rollout baseline）：

* Advantage **零均值**（greedy-rollout 下 sample 多数跑不赢 greedy，advantage 常年为负）；
* 不用额外 forward pass 训 critic / clone policy → 省算力；
* **抗局部极小**：N 条异构轨迹互相竞争，不像 greedy-rollout 那样 actor-critic 一起 premature converge。

### **3. 推理：Multi-Greedy + Instance Augmentation**

**模式做法缺点**greedyargmax 单条只出一个解samplingsoftmax 采 N 条取 best采样质量 ≤ greedy，要采很多

POMO 推理：**N 个不同起点 → N 条 deterministic greedy 轨迹 → 取 best**。N 条 greedy **普遍优于** N 条 sampled。

还加了 **Instance Augmentation**：对 2D routing 做坐标变换（翻转 / 旋转，Table 1 给的 ×8 组合），等价于“换个角度看同一个问题”，进一步榨性能。KP 没有天然几何 aug，所以不加。

---

## **三、网络与实验设置**

* **Policy Network**：直接复用 Kool 的 **Attention Model**（Encoder-Decoder + dot attention）

  + Encoder 不变，只算一次（与 N 无关）；
  + Decoder 把 N 个 query 堆叠，attention 并行出 N 条轨迹；
  + TSP 的 START token 去掉，$h\_{(c)}(t=1)$ 直接等于 $h\_i$（第 i 个起点 embedding）；
* **训练**：batch=64，Adam lr=1e-4，Titan RTX 上 TSP100 每 epoch ~7 min，2000 epoch 收敛（200 epoch 就差不多了）；
* **问题**：TSP20/50/100、CVRP20/50/100、KP100/200。

## **五、三个贡献（论文自己列的）**

1. **识别并利用 CO 解的对称性** → 多起点 rollout 探索；
2. **共享 baseline** → 低方差 + 抗局部极小；
3. **Multi-greedy 推理 + instance augmentation** → 比传统 sampling 高效。

---

## **六、一点延伸（附录里的干货）**

* Augmentation 还能玩**非单位正方形**的：任意角度旋转、小平移、小缩放，只要网络还能泛化就值得试（Appendix A.1）；
* 对 **RNN/LSTM/带 pos-encoding 的 Transformer**，输入重排也能当 augmentation（N! 种），比 ×8 坐标变换更猛；
* ×8 aug **套在原 AM 上也能用**：TSP100 gap 从 3.51% → 1.67%，等价于采 1280 条的效果但快得多（Table 5/6）——说明 aug 是通用推理技巧，不绑 POMO。

> 💡 局限：POMO 的多起点数 N 上限 = 问题规模（TSP）或被问题结构限制（CVRP 起点只能是 customer 节点，KP 是所有 item），想再扩就得靠 aug。另外 CVRP 里“depot 是固定起点、POMO 作用在第二个节点”这个细节实现时要留心。
